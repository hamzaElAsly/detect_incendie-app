# Checklist de recette responsive manuelle

Date de préparation : 29 juillet 2026

Cette checklist n'atteste aucune validation navigateur. Chaque case doit être cochée manuellement dans Chrome, Firefox, Edge et Safari (si disponible), en thèmes clair et sombre, avec navigation clavier.

## Largeurs à tester

- [ ] 320 px
- [ ] 375 px
- [ ] 390 px
- [ ] 430 px
- [ ] 768 px
- [ ] 1024 px
- [ ] 1280 px
- [ ] 1440 px
- [ ] 1920 px

## Pages

- [ ] Login
- [ ] Dashboard
- [ ] Factories
- [ ] Members
- [ ] Users (liste, création, détail, édition)
- [ ] Roles
- [ ] Camera Health (liste et détail)
- [ ] Alert Recipients
- [ ] API Clients (liste, création, secret ponctuel, détail)
- [ ] Plans
- [ ] Subscriptions
- [ ] Profile (avatar, préférences et sécurité)

## Contrôles par page

- [ ] Aucun défilement horizontal hors tableaux explicitement scrollables
- [ ] Navigation, menus, modales et confirmations accessibles
- [ ] Champs, erreurs et boutons visibles sans chevauchement
- [ ] Tableaux lisibles ou scrollables
- [ ] Focus clavier visible
- [ ] Contraste et badges lisibles dans les deux thèmes
- [ ] Images et avatar sans déformation
- [ ] Textes longs, identifiants et secrets sans rupture de mise en page
